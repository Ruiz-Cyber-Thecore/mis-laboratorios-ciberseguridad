# Dual-Purpose URL Analytics & Reconnaissance Tool

Este proyecto es una herramienta ligera de automatización diseñada con un enfoque híbrido de doble propósito: Inteligencia Comercial (Business Intelligence) y Ciberseguridad Ofensiva (OSINT / Simulaciones de Red Team). El script genera enlaces acortados estadísticos que capturan métricas de red y geolocalización por IP en milisegundos, operando a nivel de backend.

---

## 🎯 Casos de Uso (Doble Propósito)

### 1. Enfoque Comercial (Ventas e Inteligencia de Negocios)
* **Auditoría de Pasarelas de Pago:** Permite validar la procedencia geográfica real de los compradores en formularios de pago externos.
* **Análisis de Canales de Tráfico:** Monitorea de qué redes sociales o aplicaciones provienen los clics en tiempo real.
* **Cero Fricción:** Captura métricas analíticas esenciales de ubicación sin interrumpir el flujo de compra ni requerir registros complejos de cookies.

### 2. Enfoque de Ciberseguridad (Seguridad Ofensiva / OSINT)
* **Fase de Reconocimiento Pasivo:** Actúa como un *IP Logger* para mapear la infraestructura técnica del objetivo antes de una auditoría autorizada.
* **Simulaciones de Ingeniería Social:** Útil para ejercicios de concientización y pruebas de Red Team para medir la susceptibilidad de los usuarios ante enlaces externos.
* **Análisis de Evasión de Controles:** Demuestra cómo la captura de metadatos a nivel de capa de transporte (IP y encabezados HTTP) opera al ejecutarse en el lado del servidor (backend).
